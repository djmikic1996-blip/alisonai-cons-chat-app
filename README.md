# AlisonAI

**A real-time, collaborative chat and collaboration application built with React and TypeScript.**

This project demonstrates robust real-time capabilities including synchronized state, user presence tracking, and isolated feature modules.

---

## 🚀 Key Features

*   **Collaborative Chat:** Real-time messaging interface with typing indicators.
*   **Shared Counter:** Synchronized counter state across all active user sessions.
*   **User Presence:** Real-time tracking of active user activity and status.
*   **Modular Design:** Multi-user interaction support organized into a feature-based architecture.

## 🛠 Tech Stack

The application is built using modern front-end technologies:

*   **Vite:** A fast build tool and development server.
*   **React & TypeScript:** Core application framework and strong typing support.
*   **Tailwind CSS:** A utility-first CSS framework for rapid styling.
*   **MUI (Material UI):** For high-quality prebuilt UI components.
*   **Lucide-React:** For lightweight and consistent iconography.
*   **Prettier & ESLint:** Ensuring consistent code formatting and quality standards.
*   **Jest:** The testing framework used for all unit tests.

## ⚙️ Setup Instructions

To get a local copy up and running, follow these simple steps.

### Prerequisites

Ensure you have Node.js and npm installed on your system.

### Installation

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/djmikic1996-blip/alisonai-cons-chat-app.git
    cd alisonai-cons-chat-app
    ```
2.  **Install dependencies:**
    ```bash
    npm install
    ```

### Running the Application

Start the local development server:

```bash
npm run dev
